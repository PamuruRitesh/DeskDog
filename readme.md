# DeskDog

DeskDog is a personal interest-based IoT project that aims to create a desktop companion that sits on the desk and keeps me company while I work.

The first version is built using an **ESP32** and a **0.96" OLED display** to render a simple dog with expressive animations. The long-term goal is to evolve DeskDog into an interactive desktop companion with emotions, animations, desktop synchronization, and AI-powered interactions.

## Vision

* Desktop companion with expressive animations
* Modular embedded software architecture
* Real-time clock and Wi-Fi connectivity
* Desktop synchronization
* Future AI integration
* Upgrade from OLED to a TFT display for richer graphics

## Hardware

* ESP32 DOIT DevKit V1
* 0.96" I²C OLED Display
* Breadboard
* Jumper wires

## Development Workflow

Development happens on the **`test`** branch. After new features are implemented, tested, and verified, they are merged into the **`main`** branch.

Using a separate development branch helps isolate bugs, makes experimentation safer, and allows stable releases on the main branch.

This repository documents the complete journey of building DeskDog—from the first blinking eyes to a fully interactive desktop companion.
