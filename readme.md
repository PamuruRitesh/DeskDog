# 🐶 DeskDog

DeskDog is an open-source IoT project that brings a small desktop companion to life using an ESP32 and an OLED display. The goal is to build a companion that feels expressive and interactive through animations, behaviors, and eventually desktop integration and AI.

Instead of being just another embedded project, DeskDog is designed to explore software architecture, graphics, animation systems, and embedded programming while creating something enjoyable to interact with every day.

---

## ✨ Features (Planned)

* 🐶 Animated pixel-art desktop companion
* 👀 Natural blinking and eye movement
* 😴 Sleep and idle animations
* 😊 Emotion and behavior state machine
* 🕒 Real-time clock with NTP synchronization
* 📶 Wi-Fi connectivity
* 💻 Desktop companion integration
* 🔔 Notifications from the computer
* 🤖 Future AI-powered interactions
* 🎨 Planned upgrade from OLED to a color TFT display

---

## 🛠 Hardware

* ESP32 DOIT DevKit V1
* 0.96" I²C OLED Display (SSD1306)
* Breadboard
* Jumper wires
* USB cable

## 🧠 Software Stack
